## 📖 About

ReShade is developed by crosire and the wider ReShade community. It works as a post-processing layer that sits between the game and the graphics API, supporting DirectX 9 through 12, OpenGL and Vulkan titles. The current build ships an improved add-on system, a redesigned in-game overlay, deeper shader authoring options and per-effect performance tuning. Configuration is stored in preset files so a tuned look can be carried between sessions and shared with other users.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Overlay does not appear in game | Confirm the correct graphics API was selected during install for that title. |
| Game crashes on launch after install | Remove the injected DLL from the game folder and reinstall selecting a different API. |
| Depth buffer effects look flat | Enable depth buffer access in the overlay settings for the active API. |
| Shaders fail to compile | Update your GPU driver and clear the shader cache folder. |
| FPS drop after enabling many effects | Disable heavy effects or lower per-effect quality in the overlay. |
| Preset not loading | Check that the preset file uses the .ini extension and matches the installed ReShade version. |
